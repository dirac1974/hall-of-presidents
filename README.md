# Hall of Presidents — Memory Palace

A calm, anxiety-free web game that helps kids learn the 47 U.S. presidents **in order**, with their numbers, using dual-coding and Memory Palace techniques.

**Live site (after enabling Pages):** https://dirac1974.github.io/hall-of-presidents/

## How to play
Just open the page. No install needed. Works great on phones.

## What is built (v0.1)
- All 47 presidents with kid-friendly mnemonic images (text + emoji)
- Soft state machine: new → practicing → getting solid → shining
- Consecutive-success advancement (gentle, never punishes)
- Hall view with glowing portrait frames
- Soft progress pips
- Learn + Practice modes
- Positive toasts only
- Parent view (numbers hidden from kids)
- Progress saved in the browser (localStorage)

## Enabling GitHub Pages
1. Go to the repo → **Settings** → **Pages**
2. Under "Source", choose **Deploy from a branch**
3. Branch: `main` / folder: `/ (root)`
4. Save. The site will be live in 1–2 minutes at the URL above.

## Custom domain (Squarespace)
Point one of your existing domains to this GitHub Pages site so everything stays in one place:
1. In GitHub Pages settings, add your custom domain (e.g. `presidents.yourdomain.com`)
2. In Squarespace DNS, add a CNAME record pointing to `dirac1974.github.io`
3. (Optional) Enable "Enforce HTTPS" in GitHub Pages

This costs $0 extra.
