# Hall of Presidents — Memory Palace

**Live site:** https://dirac1974.github.io/hall-of-presidents/

## Status (Aug 21, 2026)

The multi-profile version and the first 14 beautiful mnemonic illustrations are ready.

**To make them appear on the live site**, please do this quick upload (takes about 90 seconds):

1. Download these two files from the chat:
   - `index.html` (the full multi-profile game)
   - `presidents-images.zip`

2. Unzip the zip file so you have the individual `pres-01.jpg` … `pres-16.jpg` files.

3. Go to this repository → click **Add file** → **Upload files**.

4. Drag **both** the new `index.html` **and** all the `pres-XX.jpg` files into the box.

5. Click **Commit changes**.

After GitHub Pages rebuilds (usually under 2 minutes), the live site will have:
- Multi-kid profiles (“Who is playing?”)
- The illustrated memory-palace cards for presidents 1–13 + Lincoln

Thank you!
